Configuración de API Claude (Anthropic)

Ingresa tu API Key de Claude (Anthropic) para ejecutar scraping real sobre los portales de remates. Claude usa su herramienta web_fetch para leer las páginas y extraer los datos verdaderos.

Cómo obtener tu API Key de Claude (pasos)
  1. Entra a console.anthropic.com y crea tu cuenta.
  2. Ve a Settings → API Keys (o "API Keys" en el menú lateral).
  3. Haz clic en "Create Key", ponle un nombre y cópiala (empieza con sk-ant-).
  4. En Billing → Credits agrega saldo (mínimo ~US$5) — el scraping consume tokens de tu cuenta.
  5. Pega la clave aquí y presiona Guardar.
Seguridad: la clave se guarda en tu navegador y se envía directo a la API desde esta página. Úsala solo en tu equipo personal. No publiques este sitio con tu clave real.
